# CleanWordCounter Chrome & Edge Extension

A production-ready Manifest V3 browser extension for **CleanWordCounter**.

## Features Included
1. **Highlight & Right-Click:** Highlight any text on any website &rarr; right-click &rarr; click **"Count Words with CleanWordCounter"** to see an immediate in-page floating pill with word count, character count, and reading time.
2. **Instant Toolbar Popup:** Click the pinned browser icon to type or paste text with real-time stats, clean text helper, and quick link to [cleanwordcounter.com](https://cleanwordcounter.com).
3. **Auto-Selection Grab:** If you highlight text on a webpage and click the extension icon, it automatically fills the popup with your highlighted text!
4. **100% Private & Ad-Free:** Zero remote tracking, zero telemetry.

---

## How to Test It Locally (Takes 15 Seconds)

1. Open Google Chrome (or Microsoft Edge / Brave).
2. Go to `chrome://extensions/` (or `edge://extensions/`).
3. Toggle on **Developer mode** in the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select the `extension` folder inside this project directory (`c:\Users\AJINKYA JOSHI\Downloads\saas2\extension`).
6. Pin the extension to your toolbar. Test selecting text on any website or clicking the icon!

## How to Publish to the Chrome Web Store

1. Zip the files inside the `extension/` folder into a `.zip` archive (e.g. `cleanwordcounter-extension.zip`).
   *(Include `manifest.json`, `popup.html`, `popup.css`, `popup.js`, `background.js`, `icon48.png`, `icon96.png`, `icon128.png`)*.
2. Visit the [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole).
3. Pay the one-time $5 Google developer registration fee (if not already paid).
4. Click **"New item"** and upload `cleanwordcounter-extension.zip`.
5. Fill out the store listing:
   - **Title:** `Clean Word Counter: Ad-Free Word & Character Count`
   - **Category:** Productivity / Workflow & Planning
   - **Description:** Highlight your key differentiators: 100% private, zero ads, instant reading time.
   - **Link:** Point support/website to `https://cleanwordcounter.com`.
6. Click **Submit for review**. Usually approved within 24–48 hours!
